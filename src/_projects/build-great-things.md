Developed and delivered an evening class on Ruby on Rails between 2012 and 2014 - a starting point for people who wanted to grow their coding skills and ship a first web app. Over a few weeks, attendees covered:

- The basics of Ruby
- Building databases using migrations
- The architecture of Rails apps
- Logins and authentication

You can find the slides for the first session [here](https://www.slideshare.net/slideshow/ror-101-session-1/10616322#1).
