With product studio [Lumi](https://www.lumi.studio/), I designed and built the privacy-centric Rails API/backend for [Third](https://www.thirdapp.co/) - a private app that helps women record experiences safely, recognise patterns, and access support without pressure to report before they’re ready.

My work covered the backend from conception through production: REST API for authentication and sync, encrypted note-taking, recovery flows, admin tooling, and Kamal-based staging/production deployment (credentials, workers, ops). The client is React Native.

Stack highlights: Ruby on Rails 8, Devise, Solid Queue, ActiveAdmin, Postmark, Docker/Kamal.
